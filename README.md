# NUMI — Academic Hub & Peer Acceleration Platform

Minimalist, editorial dark-mode university hub landing page.

## ✨ Features

- **Monochromatic Dark Aesthetic**: Pitch black (`#0b0b0b`), deep charcoal cards (`#141414`), 1px borders (`#262626`), high-contrast pure white typography with JetBrains Mono & Inter.
- **Cinematic Logo Reveal & Living State**: One-time cryptographic decode sequence upon entrance, seamlessly transitioning into an organic breathing luminescent monolith with titanium shimmer.
- **Massive Typographic Cursor Trail**: High-performance HTML5 canvas particle trail with bold 46px monospace symbols (`>`, `_`, `/`), orienting along movement angle with smooth cinematic decay.
- **Collapsible Curriculum Blocks**: 6 core disciplines (Go/C++, ICT, History of Kazakhstan, AI Fundamentals, Calculus, and Tomorrow School accelerator), closed by default for a clean, minimalist experience.
- **PRO Pass & Interactive Booking**: Two-tier membership structure and interactive modal for mentor bookings.

## 🚀 Quick Start

Open `index.html` directly in any modern browser:

```bash
open index.html
```

Or preview the React component with `NumiLanding.jsx`.
